# xiuxian-game

手机优先的文字修真游戏 / SillyTavern 扩展。

## 安装

在酒馆扩展管理中安装 `https://github.com/gutake520/xiuxian-game.git`，分支 `main`；更新后刷新页面。

## 当前功能

角色创建与独立存档、人物页、宗门拜师、储物与基础商店、功法填数学习、主修挂机及彩色打砖块修炼。人物页显示修为进度与灵石。

新旧存档初始灵石为二十，仅补齐一次；铁剑与布衣各五灵石，《引气诀》十灵石，也可拜师获得。完成学习并设为主修后每分钟增加 0.5 修为，每个本地现实日最多计入两小时，离线按每天上限累计。

小游戏首版三次失手机会；有主修时每块两点、清场六十点，无主修时有效练习只得一点。小游戏尚可继续调节。小境界满修为自动提升，筑基及战斗暂不开放。黑市和储物扩容仅预留入口，暂无收费操作。

## 目录速查

| 位置 | 用途 |
| --- | --- |
| `index.js` | 启动组装及尚未迁移的原有页面 |
| `core/` | 统一行动与保存协调 |
| `data/` | 境界、功法、物品及数值 |
| `systems/` | 修炼、学习、储物等规则 |
| `storage/` | IndexedDB 存档与旧档迁移 |
| `ui/` | 各功能界面 |
| `styles/` | 已拆分的功能样式 |
| `tests/` | 核心规则回归验证 |

详见 [目录说明](docs/STRUCTURE.md)。未开发模块仍是注释占位；`index.html` 只是早期独立演示，酒馆以 `manifest.json` 为入口。

## 验证

开发时先执行 `npm install`，再运行 `npm test`；酒馆安装扩展无需安装 npm 依赖。
