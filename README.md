# xiuxian-game

手机优先的文字修真小游戏 / SillyTavern 扩展。

当前版本：主页视觉原型。

- 零外链图片依赖
- CSS + 内嵌 SVG 山景/月相
- 右侧悬浮图标，可拖动并记忆位置
- 点击展开游戏面板，关闭后恢复悬浮图标
- 已为人物、储物、地图、设置预留入口

## 安装

在 SillyTavern 的「安装扩展」窗口中粘贴下面的 Git URL：

```text
https://github.com/gutake520/xiuxian-game.git
```

分支可填写：

```text
main
```
