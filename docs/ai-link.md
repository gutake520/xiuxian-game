# 角色同行：基础 AI 联动

在游戏设置中打开「角色同行 · AI 联动」。先开启信息同步，再开启代操作。两个开关默认关闭，刷新页面后也会关闭。酒馆需开启函数调用，所选模型和中转服务都需要支持工具调用。

当前支持：读取可见人物、储物、装备与功法信息；坊市购买装备和丹药；服药、换装、设置已学会的主修功法；炼气与筑基秘境探索及到时结算；当前战斗的攻击、已装备主动功法、跳过与逃跑。无需专用角色卡或额外 API 密钥。

主动修炼为实时打砖块，本版不代玩、不伪造修为奖励。设置主修后的挂机继续遵守既有计时规则。本版不支持主动挑选敌人开战、四处走走奇遇、小游戏、退宗、解除道侣或关键剧情选择。当前有特殊事件或玩家打开操作弹层时，会暂停 AI 行动。

每条正常聊天回复最多三个成功操作；停止生成、切聊天、玩家点击游戏界面或修改权限会取消旧操作凭证。每次写入在存档事务内检查存档快照，拒绝旧计划。重新生成已操作过的玩家消息不再改变游戏；编辑成新消息视为新任务。聊天删除不会回滚已发生的游戏变化。每次行动都写入既有游戏日志；工具结果保留给模型生成回复。

首次 AI 操作前，自动在本浏览器保留该角色原始存档；备份失败则不执行操作。可在角色同行页面下载备份，再通过现有存档导入恢复。浏览器备份不能抵抗清除站点数据，测试前建议额外导出五世存档。
