# 青山手札界面

统一米白纸面、浅青山景、深绿正文与少量朱砂提示，覆盖扩展主页、人物、行囊、地图、宗门、商店、战斗、创建角色和小游戏。使用本地字体回退与仓库内 SVG，不依赖在线字体或图片服务。

全局样式限定在 `#xg-panel` 内，主题变量集中在 `style.css`。各功能样式继续保留原有棋盘、动画和点击区域结构。此次修改不变更存档格式或战斗规则。

`ui-preview.png` 为示例存档截图，仅展示界面。
