# 九宗奇遇：抓叛徒

入口：山河图 → 四处走走 → 九宗山门。触发后可从「抓叛徒 · 继续排查」打开名册。九宗共用一个存档进度，每次触发抽取委托宗门；题面按固定顺序推进。

每行、每列、每个颜色分组各有一名叛徒，叛徒不能横向、纵向或斜角相邻。分组同时显示编号和边界，不只依赖颜色识别。可切换圈定/排除模式，重复点击取消，支持撤销和清空。没有计时、扣血或错误次数限制，提交错误只提示规则冲突。

- 共三十关，从 4×4 到 10×10。每个分组连通，每关恰有一个解。
- 题面存于 `data/traitor-levels.js`，运行时不生成随机棋盘。全部通过独立枚举求解器及无猜测排除法校验。
- 排序参考固定求解策略下的排除步数及多候选推理次数；这是难度设计指标，实际体感仍因人而异。
- 触发沿用每日最多七次奇遇的总额度。未完成的名册不会被新奇遇覆盖，也不重复占用额度。
- 标记和撤销记录随存档保存，返回或刷新后可继续。通关只结算当前关，没有「下一关」按钮。
- 下次重新触发才开始下一关。第三十关完成后不再触发这条调查，不循环。
- 默认每四关一档，奖励分别为 2～9 灵石。奖励只在提交合法名册时结算，重复提交不会重复发奖。

验证：`npm test`。新增测试覆盖三十关唯一解、区域连通、无猜测推理与难度排序、奇遇额度、保存恢复、逐关结算、防重复领奖以及交互异常恢复。
